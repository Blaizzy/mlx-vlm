# K2 Horizon (e2e implementation)

Full end-to-end port of IFM/K2-Horizon family for mlx-vlm.

Supported variants:
- K2-Horizon-0.9B (1B params)
- K2-Horizon-3.7B (5B params)
- K2-Horizon-7B (9B params)
- K2-Horizon-32B (35B params)
- K2-Horizon-375B-A23B (379B params)
- K2-Horizon-MoVA-36B-A4B (37B params, vision)

Module: `mlx_vlm/models/k2_horizon/`
Worktree: `~/mlx-vlm-k2-worktree`
